# Generátor hesel a analýza entropie

## Popis projektu 
Aplikace, která umí generovat bezpečná hesla a dokáže ohodnotit sílu hesla zadaného uživatelem na základě matematické entropie a slovníkových vzorů.

## Záměr
Vytvoření programu pro generování bezpečných a silných hesel, která nebyla prolomena.
